# TEXroad
Textile waste is a serious environmental problem, as it pollutes land and water and releases harmful chemicals when burned or dumped in landfills. This project aims to recycle textile materials for city infrastructure, including roads, bicycle lanes, and walking paths. The waste is processed into a special form that gives it strength, flexibility, and durability, allowing it to be safely mixed with construction materials.

Pilot areas will be created to test how these new surfaces perform under traffic, weather, and temperature changes. The project also involves local communities, authorities, and companies to raise awareness about recycling and sustainable urban planning. People will learn how waste materials can be safely repurposed to build useful infrastructure.

Ultimately, this project reduces textile waste, protects the environment, and creates safe, green, and sustainable spaces for walking, cycling, and driving. It provides a practical model that other cities can adopt, contributing to a smarter and more responsible urban future.
